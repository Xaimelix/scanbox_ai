## 2) Краткое описание проекта
ScanBox AI — модульная платформа для 3D-цифровизации, которая собирает данные захвата (RGB, глубина/LiDAR) и превращает их в готовые цифровые активы для E-commerce, AR превью и дальнейших рабочих процессов (инжиниринг, производство). Архитектура разделена на слои: управление, захват, реконструкция, облачная обработка и экспорт/доставка артефакта.

Основной подход: захват RGB + опционально LiDAR, реконструкция через 3D Gaussian Splatting (gsplat) по умолчанию, оркестрация через Nerfstudio, возможность облачных вычислений для больших задач и экспорт в GLB/USDZ + веб-просмотр.

## 3) Цели проекта
- Построить рабочий MVP: захват данных, базовую реконструкцию и экспорт.
- Обеспечить модульность на уровне архитектуры и возможности замены компонентов.
- Обеспечить экспорт готового актива и веб-просмотр по умолчанию.
- Позже добавить LiDAR-улучшения и облачную обработку для масштабирования.

## 4) Архитектура (кратко)
- Контроль/Управление (Control Layer)
- Захват (Capture Layer) — RGB камеры, LiDAR/depth, turntable/освещение, калибровка
- Реконструкция (Reconstruction Layer) — Nerfstudio, 3DGS/gsplat, NeRF
- Облачная обработка (Cloud Processing Layer) — очереди, подготовка данных, обучение/рендера
- Экспорт/Доставка (Product/Export Layer) — GLB, USDZ, веб-обозреватель

Ключевые паттерны: модульность, возможность замены бэкенда реконструкции, опциональный перенос тяжелых вычислений в облако.

## 5) Входы и выходы
- Вход: RGB изображения, Depth/LiDAR, калибровочные данные, метаданные захвата
- Выход: GLB, USDZ, наборы веб-ресурсов для просмотра (web viewer)

## 6) MVP Roadmap (кратко)
- Phase 1 — Capture Prototype: пайплайн захвата, контроль освещения, поворот объекта, базовая запись метаданных, калибровка.
- Phase 2 — Reconstruction Baseline: упаковка датасета, Nerfstudio-оркестрация, дефолт 3DGS/gsplat, превью, базовые проверки качества.
- Phase 3 — Export and Delivery: экспорт GLB, веб-превью, USDZ (путь для AR), упаковка результатов.
- Phase 4 — LiDAR Enhancement: выравнивание геометрии depth/LiDAR, предобработка тучи точек, привязка depth к реконструкции.
- Phase 5 — Cloud Processing Layer: обертка API облака Intelion, удаленная обработка, сбор логов.
- Phase 6 — Operational Hardening: устойчивость к ошибкам, валидация калибровки, единообразие наименований файлов, документация.

## 7) Ключевые технологии
- 3D Gaussian Splatting / gsplat (приоритет MVP)
- Nerfstudio (оркестрация, прототипирование NeRF-пайплайнов)
- NeRF (пограничные/сложные сцены)
- LiDAR / трактовка depth для геометрии
- Облачная обработка для больших задач

## 8) Риски и ограничения
- Плохое качество захвата из-за освещения/дрожания камеры
- Неточности калибровки и смещение масштаба
- Сжигание функционала (scope creep) и избыточная сложность
- Стоимость и надежность облачных вычислений

## 9) Метрики и критерии успеха
- Успешный сбор и повторяемый захват объектов
- Базовая реконструкция без ручных правок
- Корректный экспорт в GLB/USDZ и веб-просмотр
- Возможность локального запуска MVP и параллельной миграции в облако
